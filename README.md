<h1>Cоздание библиотеки для пользователя</h1>

<h2>Отчет о разработке:</h2>

  <p>Этот отчет описывает работу, выполненную по создании библиотеки пользователей, в неё вошли структура с основными полями, редактирование и чтение данных о пользователях в системе, добавление нового пользователя, удаление пользователя, поиск пользователя, фильтрация всех пользователей.  Целью было создание надежного и простого способа управления информацией о пользователях.</p>

  <h2>Описание выполненных задач</h2>

  <ul>
    <h2>Часть Семёна:</h2>
    <h2><strong>Реализация функции чтения пользователей:</h2></strong>
      <p>Была разработана функция, позволяющая читать данные о пользователях из внешнего источника (в данном случае, CSV-файл). Функция обеспечивает корректное чтение данных и отображение их в удобном формате.</p>
      <p class="highlight">Ключевые аспекты:</p>
      <ul>
        <li>Чтение данных из CSV файла.</li>
        <li>Обработка ошибок при чтении (например, файл не найден, некорректный формат данных).</li>
        <li>Предоставление простого способа доступа к данным о пользователях.</li>
      </ul>
    </li>
    <h2><strong>Реализация функции редактирования пользователей:</strong></h2>
      <p>Была разработана функция, позволяющая изменять данные о существующих пользователях. Функция предоставляет возможность редактировать различные атрибуты пользователя, такие как имя, фамилия, возраст и т.д.</p>
      <p class="highlight">Ключевые аспекты:</p>
      <ul>
        <li>Получение идентификатора пользователя для редактирования.</li>
        <li>Отображение текущих данных пользователя.</li>
        <li>Прием новых значений для атрибутов пользователя.</li>
        <li>Сохранение измененных данных во внешний источник (CSV-файл).</li>
        <li>Обработка ошибок при сохранении.</li>
      </ul>
    </li>
  </ul>
