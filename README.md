<h1>Создание библиотеки для пользователя</h1>

<h2>Отчет о разработке:</h2>

<p>
  Этот отчет описывает работу, выполненную по создании библиотеки пользователей. В неё вошли структура с основными полями, редактирование и чтение данных о пользователях в системе, добавление нового пользователя, удаление пользователя, поиск пользователя, фильтрация всех пользователей. 
  Целью было создание надёжного и простого способа управления информацией о пользователях.
</p>

<h2>Описание выполненных задач</h2>

<ul>
  <h2>Часть Семёна:</h2>

  <h2><strong>Реализация функции чтения пользователей:</strong></h2>
  <p>
    Была разработана функция, позволяющая читать данные о пользователях из внешнего источника (в данном случае, CSV-файл). 
    Функция обеспечивает корректное чтение данных и отображение их в удобном формате.
  </p>
  <p class="highlight">Ключевые аспекты:</p>
  <ul>
    <li>Чтение данных из CSV файла.</li>
    <li>Обработка ошибок при чтении (например, файл не найден, некорректный формат данных).</li>
    <li>Предоставление простого способа доступа к данным о пользователях.</li>
  </ul>

  <h2><strong>Реализация функции редактирования пользователей:</strong></h2>
  <p>
    Была разработана функция, позволяющая изменять данные о существующих пользователях. 
    Функция предоставляет возможность редактировать различные атрибуты пользователя, такие как имя, фамилия, возраст и т.д.
  </p>
  <p class="highlight">Ключевые аспекты:</p>
  <ul>
    <li>Получение идентификатора пользователя для редактирования.</li>
    <li>Отображение текущих данных пользователя.</li>
    <li>Прием новых значений для атрибутов пользователя.</li>
    <li>Сохранение измененных данных во внешний источник (CSV-файл).</li>
    <li>Обработка ошибок при сохранении.</li>
  </ul>
</ul>

<ul>
  <h2>Часть Головачевой Е.М.:</h2>

  <h2><strong>Реализация функции добавления пользователей:</strong></h2>
  <p>
    Была разработана функция, позволяющая добавлять новых пользователей в систему. Пользователь вводит необходимые данные (ID, имя, фамилию, страну, возраст), 
    после чего информация сохраняется в список и экспортируется в CSV-файл.
  </p>
  <p class="highlight">Ключевые аспекты:</p>
  <ul>
    <li>Ввод данных нового пользователя через консоль.</li>
    <li>Валидация введённых значений (например, корректный ID и возраст).</li>
    <li>Добавление нового пользователя в коллекцию.</li>
    <li>Сохранение обновлённой информации в файл CSV.</li>
  </ul>

  <h2><strong>Реализация функции поиска пользователей:</strong></h2>
  <p>
    Разработан механизм поиска пользователей по различным критериям (имя, фамилия, страна, возраст). Пользователь может указать один или несколько параметров, 
    и система выполнит фильтрацию по введённым значениям.
  </p>
  <p class="highlight">Ключевые аспекты:</p>
  <ul>
    <li>Поддержка частичного поиска по нескольким полям.</li>
    <li>Гибкая логика фильтрации (учитываются только заполненные поля).</li>
    <li>Отображение результатов в читаемом формате.</li>
  </ul>

  <h2><strong>Реализация функции вывода всех пользователей:</strong></h2>
  <p>
    Была реализована функция отображения полного списка всех пользователей в системе. Это позволяет легко получить общую картину хранящейся информации.
  </p>
  <p class="highlight">Ключевые аспекты:</p>
 
  <ul>
    <li>Перебор всех записей в коллекции пользователей.</li>
    <li>Вывод данных в структурированном и понятном виде.</li>
    <li>Обработка ситуации, когда список пользователей пуст.</li>
  </ul>
</ul>

  </p>
